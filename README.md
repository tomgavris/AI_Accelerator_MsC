# Systolic Array

 This prject details the creation of a Systolic Array (**SA**), which will be used in a Artificial Intelligence (**AI**) accelerator for the purposes of my intersnhip at "Universität Bremen".

## Description

The purpose of this project is to create a fully functional Systolic Array (**SA**), comprised of 4x4 Processing Elements (**PE**). In the first part of the development process a SA was created with simple processing elements, found in the folder **SA_with_PE**, and later the processing elements were modified into Dot Product Processing Elements (DPPE), found in the folder **DPPE_SA**.
The later SA will be later implented in an Artificial Intelligence (**AI**) accelerator, which is the final goal of this project.
