# Systolic Array

 This prject details the creation of a Systolic Array (**SA**), which will be used in a Artificial Intelligence (**AI**) accelerator for the purposes of my intersnhip at the Universität Bremen.

## Description

The purpose of this project is to create a fully functional Systolic Array (**SA**), comprised of 4x4 Processing Elements (**PE**). This SA will be later implented in an Artificial Intelligence (**AI**) accelerator, which is the final goal of this project.
